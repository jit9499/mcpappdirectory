Frequently Asked Questions

What is an MCP server?

An MCP (Model Context Protocol) server is a bridge that lets AI assistants like Claude, Cursor, and VS Code Copilot connect to external tools — databases, APIs, file systems, search engines, and more. Think of it as a plugin that gives AI superpowers.

How are quality scores calculated?

Each server is scored on 8 parameters using real GitHub data: code recency (20pts), documentation quality (15pts), test coverage (10pts), auth/security patterns (10pts), star velocity (15pts), security audit (15pts), install documentation (15pts), and an activity bonus (5pts). No AI hallucination — just data.

How often are scores updated?

Scores are refreshed regularly using live GitHub data. A server's score can go up or down based on real activity — recent commits, new stars, updated docs, and more.

Can I submit my own MCP server?

Yes! Visit our Submit page to add your MCP server to the directory. It will be automatically scored on all 8 parameters.
